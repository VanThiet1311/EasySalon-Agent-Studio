                  Mô hình OpenCode (qua 9router proxy):
                

                

                  Chọn mô hình AI kết nối qua proxy 9router nội bộ (127.0.0.1:20128) để OpenCode thực thi.
                

              


              

                
              


              

                

                  Cơ chế thực thi OpenCode: Mỗi tác vụ được gán phiên làm việc độc lập với session ID dạng ses_<task_id>. OpenCode stream từng bước tool-use qua JSON event mà không lock terminal stdin, giúp đạt tốc độ thực thi tương đương terminal trực tiếp.

                1. Biến môi trường (.env / os.environ) (Ưu tiên cao nhất nếu được thiết lập)
